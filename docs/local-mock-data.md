# Локальные моковые данные

Данные сохраняются в локальной БД и доступны через настоящий API всем экранам Vue.
Загрузка: `npm run dev` (Docker, миграции и моки) или `make demo` для уже запущенной среды.
Повторная загрузка не дублирует записи и сохраняет изменения пользователя.
`make demo-passwords` перевыпускает только пароли демонстрационных аккаунтов.

## Изоляция и миксины

`common/demo_mixins.py` содержит `LocalDemoMixin` (проверка окружения и локальной БД)
и `DemoScenariosMixin` (подмешивание связанных учебных сценариев к основному набору).
Их использует команда `demo_data`; весь набор загружается одной транзакцией.
`LOCAL_DEMO_ENABLED=True` задан только в development settings. Дополнительно требуется
`DEBUG=True` и SQLite либо PostgreSQL с адресом `postgres`, `localhost`, `127.0.0.1`, `::1`.
В production флаг выключен; deployment и обычный `make up` не вызывают загрузку.
Эта защита предполагает отдельную локальную БД: не направляйте localhost через туннель на production.
Демо-публикация и конкурс имеют `is_demo=True` и исключаются из production seed.

Источники: `common/management/commands/demo_data.py`, `common/demo.py`,
`development-fixtures/student-import.csv`. Значения ниже описывают первую загрузку;
ID, пароли, токены и временные метки генерируются и не фиксируются в документации.

## Учреждения и обучение

- Школа: «Демонстрационная школа», тип `school`.
- Вуз: «Инженерный университет · DEMO», тип `university`.
- Классы школы: «9А · DEMO», «9Б · DEMO», учебный год `2026/2027`.
- Членства учеников начинаются в день загрузки; все три ученика записаны на курс.
- Курс: «Основы проектной деятельности», описание «Демонстрационный курс», опубликован.
- Задание «План исследования · DEMO»: «Опишите проблему и способ проверки гипотезы.»;
  критерии «Есть проверяемая гипотеза и измеримый критерий.», срок +7 дней.
- Задание «Презентация решения · DEMO»: «Опишите прототип и результаты измерений.»;
  критерии «Проблема, схема прототипа и результаты испытаний.», позиция 2, срок +10 дней.
- Работа Марии: «DEMO: прототип проверен на трёх режимах, измерения приложены в описании.»;
  отправлена и принята преподавателем, отзыв «DEMO: измеримые результаты и критерии представлены.».
  История отправки/проверки и активность CRM создаются учебными сервисами.

## Мастер-классы и партнёрство

Активное партнёрство вуза со школой: от дня загрузки на 365 дней.
Оба мастер-класса опубликованы, тема «Робототехника», формат `onsite`,
место «Университет · лаборатория 101 · DEMO», начало +14 дней, длительность 2 часа.
Регистрация открывается −1 день и закрывается +12 дней.
Описание: «Тестовое мероприятие для знакомства с записью и листом ожидания.»
Требования: «Тестовые записи, участие не является реальной регистрацией.»

| Название                                | Аудитория | Вместимость |
| --------------------------------------- | --------- | ----------- |
| Робототехника для начинающих · DEMO     | all       | 20          |
| Инженерная лаборатория партнёров · DEMO | partners  | 2           |

Записи на мастер-классы и очередь изначально пустые — их можно проверить через интерфейс.
